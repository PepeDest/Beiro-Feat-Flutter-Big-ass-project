# S5: boundaries by conditional independence

This file was written on 2026-10-24, **before** any S5 code or result existed. The calibration and results sections at the end were added later.

## Question (ROADMAP S5)
Can conditional independence find the boundary (Markov blanket) of a structure, in a world where the structure is not
marked by a special drive? (The original script failed this: its "organism" was the block with an external drive and a
supercritical gain, ORIGIN.md §3.) S5 asks two things:
1. **Blanket recovery.** Given the interior I of a planted structure, does a conditional-independence method recover its
   blanket B, so that I(I; E | B) = 0 for the rest E?
2. **Discovery.** Without knowing I, do information scores (Φ_TC of S1b, C, TC, closure) rank the planted interiors at the top?

A known problem guides the design. In driven (non-equilibrium) systems, sparse coupling does not give conditional
independence in the stationary law [AguileraMillidgeTschantzBuckley22]. So S5 compares two blanket detectors:
- **static:** conditional independence in the stationary law (zeros of the precision matrix) [Pearl88, Friston13];
- **dynamic:** zeros of the coupling (drift) matrix B, estimated from lagged covariances, B̂ = −logm(Ĉ(Δ) Ŝ⁻¹)/Δ.
  For an OU process e^{−BΔ} = C(Δ) S⁻¹ (gaussian.lagged_cov), so the estimator is exact for exact covariances.

## Worlds
N = 24 linear OU variables, D = I. Two planted structures and 12 background variables.
- Each planted structure: an interior of 3 variables (all 3 coupled to each other) and a blanket of 3 variables.
  Each blanket variable couples to 2 random interior variables of its structure and to 2 random background variables.
  Blanket variables do not couple to each other. Interior variables couple to nothing else.
- Background: random coupling graph, each pair coupled with probability 0.25.
- Coupling weights: magnitude uniform in [0.3, 0.6], random sign, the same for every edge type.
  Diagonal: A_ii = Σ_j |A_ij| + uniform[0.5, 1.5], so A is positive definite. No variable gets a special drive or noise.
- **Equilibrium family:** B = A (symmetric). Then the precision matrix is A, so the static blanket is exact.
- **Driven family:** B = A + G, with G antisymmetric on the same edges, magnitude uniform in [0.3, 0.6], random sign.
  The coupling graph is the same, but the stationary precision is not sparse in general.
- 40 test worlds per family (seed 2026). 10 separate calibration worlds per family (seed 7) set the thresholds.

## Data and detectors
- **Exact mode:** true S and C(Δ). Edge if |value| > 1e-8. This tests identifiability, with no estimation noise.
- **Finite mode:** one trajectory of 20000 samples with spacing Δ = 0.5 (exact propagator, after burn-in).
  Static: edge if |partial correlation| > t_s. Dynamic: edge if max(|B̂_ij|, |B̂_ji|) > t_d.
  t_s and t_d maximise the mean edge F1 on the calibration worlds of each family. They are fixed before the test worlds run.
- Recovered blanket of an interior I: B̂(I) = all variables outside I with an edge to I. Success: B̂(I) = B exactly.

## Rules (fixed before the run)
Recovery rate over 80 planted structures per family. Wilson 95 % interval.

| Rule | Question | Verdict per cell (detector × family) |
|---|---|---|
| B1 | Exact mode: is the blanket identifiable? | "recovers" if rate ≥ 0.8 and CI low ≥ 0.7. "fails" if rate ≤ 0.5. Else "partial". |
| B2 | Finite mode: same question with 20000 samples | same labels |
| D1 | Discovery: among all 2024 triples, what is the percentile of each planted interior by a score? Scores: Φ_TC (P + C − 0.25 TC, environment = complement, τ = 1), C, TC, closure Cl = TC(I) − I(I; rest). Exact features. | For each score and family: "finds structures" if the median percentile ≥ 0.95 and its bootstrap CI (over worlds) has low ≥ 0.90. Else "does not find". |

Description only: edge precision and recall of each detector; and, in driven worlds in exact mode, the size of the
static partial correlations between interior and exterior, against those on true edges.

**Expectations written before the run.**
- B1: static "recovers" in equilibrium and "fails" in driven worlds. Dynamic "recovers" in both.
- B2: the same pattern, a little weaker.
- D1: TC and closure "find structures", because the interiors are dense. Φ_TC "does not find", because it subtracts TC.

### One expectation was wrong
I expected the static detector to fail in driven worlds with finite data too. It recovers 99 % of the blankets. In exact
mode the precision matrix is dense (edge precision 0.17), as Aguilera et al. predict, but the extra terms are small, and
the calibrated threshold (0.07) removes them.

### Post-hoc check: drive strength (done after the results were seen)
Same 40 driven test worlds, exact mode, the drive G multiplied by a factor, static threshold 0.07:

| Drive | Max \|r\| interior–exterior (median) | \|r\| on true edges (median) | Static blanket recovery |
|---|---|---|---|
| × 1 | 0.034 | 0.149 | 1.00 |
| × 2 | 0.059 | 0.131 | 0.84 |
| × 4 | 0.076 | 0.099 | 0.46 |

### What S5 shows
1. **Conditional independence recovers planted blankets** in all 8 cells except one. The answer is not in any drive: all
   variables have the same noise and the same weight distribution.
2. **The static blanket is not exact in driven worlds**, as Aguilera et al. say. It holds only approximately, and it breaks
   down as the drive grows (recovery 1.00, 0.84, 0.46 at drive × 1, × 2, × 4).
3. **The dynamic blanket (from the coupling matrix) is exact at every drive strength.** With finite data it is a little
   noisier than the static one here (0.88 to 0.91 against 0.99 to 1.00).
4. **Φ_TC ranks planted structures at the bottom** (percentile 0.02–0.04), because it subtracts TC. TC and closure rank them
   at the top 1 %. So the S1b score that predicts viability in passive worlds is the wrong score to find structures. Internal
   integration is a cost for persistence there (S1b, R5), but it is the mark of a planted structure here.
5. C alone does not find structures (percentile 0.38–0.59).

### Limits
- The planted interiors are dense cliques with no outside coupling. So TC and closure find them partly by design. A harder
  test would plant structures that are not denser than the background.
- One size of structure (3 + 3), N = 24, and a brute-force search over triples. No search over sizes, no slow-mode
  candidates, and no test of submodularity (ROADMAP items not done).
- The finite-data dynamic detector was not tested at stronger drives.
