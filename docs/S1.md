# S1: robustness sweep over τ, p_out and N

Goal (ROADMAP S1): find out if the verdicts on H1–H4 (THEORY §5) depend on τ, p_out or N.
This file was written on 2026-10-21, **before** any S1 result existed. The results section at the end was added after the runs.

## Design
One setting changes at a time. Everything else stays at the baseline (τ = 1, p_out = 0.05, N = 6).

| Tag | τ | p_out | N | New simulation? |
|---|---|---|---|---|
| (baseline) | 1 | 0.05 | 6 | no (S0 rerun) |
| `_tau0.5` | 0.5 | 0.05 | 6 | no: τ changes only the information features, so the baseline exit data are reused |
| `_tau2` | 2 | 0.05 | 6 | no (same reason) |
| `_p0.01` | 1 | 0.01 | 6 | yes |
| `_p0.2` | 1 | 0.2 | 6 | yes |
| `_N5` | 1 | 0.05 | 5 | yes |
| `_N7` | 1 | 0.05 | 7 | yes |

All settings use 30 worlds per family, 600 trajectories, dt = 0.05, t_max = 200 and seed 2026.
The p_out settings use the same worlds as the baseline (same seeds). The N settings use new worlds.
This is not a full 3 × 3 × 3 grid (27 settings). A full grid would take about 27 runs of 30–60 minutes each.

**Modular blocks for N ≠ 6.** The code used one block of size N when N ≠ 6. That makes the modular family the same
as the driven family. S1 uses blocks [3, 2] for N = 5 and [3, 2, 2] for N = 7. This choice is arbitrary.

## Verdict rules (fixed before the runs)
All numbers come from `results/e3_summary{tag}.json` and `results/e4_merging{tag}.json`.

| Hypothesis | Supported | Partial | Not supported |
|---|---|---|---|
| H1: Φ_orig ranks structures by log V (pooled ρ, all structures) | CI low > 0 | — | CI includes 0 or CI high < 0 |
| H2: coefficient signs P > 0, C > 0, K_H < 0 in all three families | all 9 signs right and all 9 CIs exclude 0 | all 9 point signs right, one or more CIs include 0 | one or more point signs wrong |
| H3 control: equilibrium family has log R ≈ 0 | \|mean log R\| < 0.05 | — | \|mean log R\| ≥ 0.05 |
| H4: ΔΦ predicts merge synergy better than static I(A;B) (all pairs) | ρ(ΔΦ) > ρ(I(A;B)) and ρ(ΔΦ) CI low > 0 | — | otherwise |

The second half of H3 ("R is explained by features") is still not tested.

**Gate (from ROADMAP).** If H1 is "supported" in any setting, the negative result depends on the ensemble. It must then be reported as such.

Also reported for each setting: ρ(C only) among structures of equal size, because C was the best single predictor in the baseline.

## D-test: noise strength that differs between variables (rules fixed 2026-10-21, before the run)
**Why.** With D = I, a slow variable also has a large variance. Then K_H (entropy, which grows with variance) is also a
measure of slowness, and slowness gives long life. RESULTS.md gives this as the reason for K_H's mixed sign (−0.70 among
structures of equal size). The D-test breaks this link.

**Design.** Same worlds as the baseline (same seeds, same B_s and G). The noise matrix becomes D = diag(d_i), with
d_i drawn log-uniform in [1/r, r]. The drift becomes B = D (B_s + G). With G = 0 this keeps detailed balance
(B = D A with A symmetric gives S = A⁻¹ and B S = D), so the equilibrium family stays reversible and the H3 control
still holds. Variance comes from A⁻¹ and time scales come from D A, so they are no longer tied together.
Two settings: `_D2` (r = 2) and `_D3` (r = 3). N = 6, τ = 1, p_out = 0.05, and the other settings as in the baseline.
A larger r gives rates up to about 30, and the dt = 0.05 exit check then misses too many exits (LIMITATIONS §6).

**Rule.** The confound explanation is *supported* if ρ(−K_H, log V) among structures of equal size moves toward 0 by
more than 0.2 from the baseline (−0.70) in `_D3`, and `_D2` lies between the baseline and `_D3`. Otherwise it is
*not supported*. H1–H4 use the same rules as above.
(Note 2026-11-04, phase C: the corrected baseline value is −0.74; ~~the D-test runs keep the old exit check, see the results.~~)
**Superseded (2026-11-05):** the D-test runs are now redone with the corrected exit check (night run, `_D2_v2`, `_D3_v2`,
docs/RERUN.md C5). The rule is evaluated on corrected data against the corrected baseline −0.74; see the results.

### What S1 shows
1. **C is the stable predictor.** ρ(C only) among structures of equal size is between +0.48 and +0.72 in all 9 settings.
   **Superseded (2026-11-04, phase C, docs/RERUN.md):** corrected values: baseline +0.55, τ 0.5 ~~+0.68~~ +0.69, τ 2 +0.48
   (all CIs exclude 0). The range +0.48 to +0.72 stands, but the other 6 settings still use the old exit check.
2. **H4 (merging) fails in all 9 settings.** Static I(A;B) always predicts merge synergy better than ΔΦ.
   **Note (phase C):** confirmed with all merge pairs in baseline, τ 0.5 and τ 2 (ρ(ΔΦ) −0.17, −0.16, −0.01 against
   ρ(I(A;B)) +0.36); the other 6 settings still use the old exit check and the filtered pairs.
3. **The H3 control passes in all 9 settings** (|mean log R| ≤ 0.02 in the equilibrium family). Driven dynamics shorten life by about 17–23 % everywhere.
   **Superseded (phase C):** in baseline, τ 0.5 and τ 2 the equilibrium log R is ~~+0.019~~ exactly 0.000 (common random
   numbers); the drive shortens life by 17 % (driven, log R ~~−0.206~~ −0.190) and 22 % (modular, ~~−0.244~~ −0.245).
   The other 6 settings still use the old exit check and separate random numbers.
4. **The gate triggers.** H1 is supported at τ = 0.5 (~~+0.15~~ +0.23 [+0.12, +0.33], phase C, `_v2`) and in the D-test with r = 3 (+0.19, old exit check). So the negative H1 result of RESULTS.md depends on the ensemble and on τ, and it must be reported that way.
   **Note (phase C):** the gate still triggers on corrected data (τ 0.5). At τ 2, H1 stays not supported: ~~−0.23~~ −0.16 [−0.26, −0.07].
5. **The D-test supports the confound explanation (rule fixed before the run).** ρ(−K_H) among structures of equal size goes from −0.70 (D = I) to −0.29 (r = 2) to −0.08 (r = 3). When variance no longer follows time scale, K_H loses most of its bad effect, and Φ_orig then predicts viability.
   **Note (phase C):** the rule uses the baseline value as reference. The corrected baseline value is ~~−0.70~~ −0.74
   [−0.78, −0.70], but the D-test runs still use the old exit check. So the D-test is not re-evaluated; the verdict above is on old data.
6. **τ changes H1 through the fixed λ (post hoc, `results/s1_lambda_scan.md`).** τ changes the scale of C (within-world sd 0.30 at τ = 0.5, 0.12 at τ = 1, 0.03 at τ = 2). K_H does not depend on τ. So λ = 0.25 gives a different C : K_H balance at each τ. In the scan, a small λ gives a positive ρ at every τ, and a large λ gives a negative ρ. P + C alone (λ = 0) gives ρ between ~~+0.32 and +0.39~~ +0.25 and +0.32 at all three τ values. This explanation was found after the results were seen. It is not a pre-registered test.
   **Superseded (phase C, `results/s1_lambda_scan_v2.md`):** the pattern stands. λ = 0 gives +0.25, +0.29, +0.32 at
   τ = 0.5, 1, 2 (old +0.32, +0.36, +0.39); λ = 0.25 gives +0.23, −0.01, −0.16 (old +0.15, −0.08, −0.23); λ = 1 gives
   −0.14, −0.18, −0.19 (old −0.21, −0.24, −0.25). The sd of C does not change (it does not depend on the exit check).

### Consequences for the claims in RESULTS.md
- Replace "Φ_orig does not predict viability" with: "Φ_orig with β = 1 and λ = 0.25 is not a reliable predictor. Its sign depends on τ and on the noise structure D. The part of Φ that predicts viability in every setting is C."
- The K_H term is the fragile part. With D = I it mostly measures slowness, not complexity. A complexity cost that does not depend on the units (LIMITATIONS §3) is needed before any λ is meaningful.
- H4 stays a clear negative result.

**Note (2026-11-04, phase C, docs/RERUN.md):** these consequences stand on the corrected data where they could be checked.
The τ dependence of H1 and the role of C are confirmed in baseline, τ 0.5 and τ 2, and H4 still fails there. The D part
("depends on the noise structure D", "with D = I it mostly measures slowness") rests on the D-test, which still uses the
old exit check.
