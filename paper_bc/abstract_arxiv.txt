Kolchinsky and Wolpert define semantic information as the information about the environment that a system needs to stay viable. Its computation needs a search over interventions. Earlier work names this cost as the main obstacle. We compute it for linear Gaussian systems. For the stored form, a Gaussian pre-garbling of the environment is one matrix P with 0 <= P <= I. The viability is an exact function of P. For an agent with one coordinate, the stored semantic information has a closed form. It is the information of the agent about the one direction of the environment that drives it. For more coordinates, noisy garblings beat deterministic coarse-grainings in 40 of 48 test systems. Non-Gaussian partitions beat the Gaussian value in 2 of 27 scalar systems. So the Gaussian value is an upper bound. For the observed form, we prove two facts. One time step never changes the viability. The directed information is at most the transfer entropy. The observed semantic information is at most the smallest sensor information of Tanaka et al. in all tests. In the median it is about six times smaller. Then we test the scores and Causal Leverage Density (CLD) on two negative controls. The first is a homeostat whose actuator does not read its sensor. The second is a set of passive bistable units. No score gives zero. Without feedback, the value of information of Kolchinsky and Wolpert is negative (we prove this). The stored semantic information is the full mutual information. CLD rates passive units above driven oscillators of the same life (AUC 0.711 [0.676, 0.748]). These scores measure correlation or memory. We fixed all rules before the runs.
